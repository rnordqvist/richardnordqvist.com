# richardnordqvist.com

Personal website of Richard Nordqvist — e-commerce strategist and owner-operator, Oslo & Gothenburg.

A single static page served with GitHub Pages. No build step: edit `index.html` and the site updates.

- `index.html` – the page, with schema.org Person data
- `robots.txt` – open to search engines and AI assistants
- `llms.txt` – plain-language summary for AI models
- `sitemap.xml`, `CNAME`, `favicon.svg`, images

Live at [richardnordqvist.com](https://richardnordqvist.com).
